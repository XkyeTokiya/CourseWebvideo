# 用途

用一张主图和两到四条图侧阅读项建立场景、解释对象或完成回扣，把关键洞察融入同一阅读区，不设置独立页底判断。

# 正例

主图保持主要视觉面积，图侧短条按观察顺序排列；标题或其中一条短条承担关键洞察，读完 insight-rail 即完成本页收束。教材原图使用时，阅读项全部放在图外。

# 反例

不要在图片上覆盖完整句、流程链、闭环或虚构界面，不要在 insight-rail 之外增加 final-judgment；教材原图不得裁切关键标注、描摹、重绘或 AI 复刻。
