# Page recipe v2 contract pointer

Recipe authoring rules used by production Agents are in [visual-rough-v4-author-contract.md](visual-rough-v4-author-contract.md#recipe媒体与跨页规则). The current recipe files in this directory are the only selectable definitions; each file is a `courseplay-page-recipe/v2` definition.

The loader and recipe-management commands are implementation details. A production Agent only reads a current recipe when selecting a page structure and reports an unlisted failure as a tooling defect.
