## 2. Episode Positioning

- 主要解释问题：工业 ID 为什么不能只停留在标签上，而要由通信模组和工业互联网终端共同承载、采集并传递？

## 4. Content Type and Narrative Strategy

- 主要类型：System mechanism。观众需要理解“工业 ID 如何落到可联网的工业对象上”，核心是对象、模块和承载路径，而不是产品选型或接口操作。
- 次要类型：Concept boundary。用主动标识载体作为上位概念，区分通信模组的连接角色与终端的现场功能角色。
- 本集叙事链：工业现场身份与互通问题 → 主动承载概念 → 通信模组的连接能力 → 工业 ID 与安全材料的承载位置 → 终端的采集/控制职责 → 终端模块组成与移动/固定分类 → 三者关系合成 → 边界收束并引向注册集。
- 解决方式：先回答“为什么需要承载”，再分别拆解模组和终端，最后将“工业 ID 锚定对象、终端产生数据、模组提供连接”合成为一条不含注册步骤的解释链。

## 6. Continuous Narration Master Script

[N001]
在工厂里，工业 ID 是设备在系统中的身份锚点，用来让后续数据持续关联到明确对象；一台设备能采集数据，并不等于这些数据天然知道“来自谁”。当终端数量增加、设备和系统彼此异构时，身份认证、跨系统交互和数据安全会同时变成问题。工业 ID 要发挥作用，必须被放进一个能够稳定连接现场对象的承载体系里。

[N002]
教材把主动标识载体定义为：可以嵌入工业设备内部，承载工业互联网标识编码以及必要的安全证书、算法和密钥，具备联网通信能力，并能主动向标识解析服务节点或标识数据应用平台发起连接，而不必等待外部读写设备触发。通信模组和通信终端，都是这个概念下的例子。

[N003]
这一定义包含四个观察点：载体嵌入设备内部，减少被盗取或误安装的可能；它能主动联网，并支持远程管理所承载的标识及相关信息；安全区域可保存证书、算法和密钥，支持加密传输与接入认证；它还面向震动、潮湿、摩擦和篡改等复杂工业环境。

[N004]
先看通信模组。它不是一张孤立的标签，而是把工业对象接入网络的一组功能单元。教材将它概括为主功能模块、天线接口单元和功能接口单元。三者分别处理核心信号与协议、连接射频天线，以及同终端主板交换信号。

[N005]
通信模组的主功能模块包括基带处理器、射频模块和电源管理模块。基带处理器负责基带信号与协议处理，是模组的核心；射频模块参与无线连接；电源管理模块保障供电。这里不延伸到产品芯片、频段或性能参数。

[N006]
工业 ID 在哪里承载？教材指出，工业标识和密钥 Applet 可以由主功能模块中的 MCU 承载。这样，模组既有连接外部网络的能力，又能把工业标识放在与设备连接的功能单元里。工业 ID 因此不只是贴在设备表面的字符，而成为设备通信过程中的身份锚点。

[N007]
天线接口单元通过 RF 天线接口连接天线；功能接口单元通过 PIN 脚或 SMT 方式与终端主板连接，提供信号输入输出。本集关注“模组连接终端、模组承载工业 ID”，不把教材示意图误读成固定电路或厂商规格。

[N008]
再看工业互联网终端。教材将它定义为连接感知延伸层和网络层、实现数据采集或汇聚并向电信网络发送数据的设备。从通信角度，它是网络的端节点；从行业应用角度，它还要提供具体行业需要的功能，所以外形和功能可以有很大差异。

[N009]
终端承担的任务比“把数据发出去”更完整：它可以采集或汇聚现场数据，进行预处理，承担加密、控制和数据传输。也就是说，终端面对的是设备和现场过程，通信模组面对的是连接和协议处理。两者配合，才能把一个工业对象的状态变成可传递、可关联的数据。

[N010]
教材给出的终端架构包括主控、网络接入、数据接入、电源和外设接口五类模块。主控组织终端功能，数据接入面对现场数据，网络接入连接网络侧，电源保障供电，外设接口连接外部设备。本集只保留职责关系，不虚构内部器件。

[N011]
按网络技术差异，教材把终端分为移动终端和固定终端。移动终端可支持蜂窝无线通信，教材以安装移动通信模块的挖掘机为例；固定终端可支持有线或近距离、短距离无线通信，教材以监控摄像头为例。这个分类只用于理解连接条件，不比较制式和性能。

[N012]
把两类对象放回承载链：终端连接现场感知和控制，采集并预处理数据；通信模组嵌入终端或设备，提供网络连接和协议处理；工业 ID 由承载单元保存并锚定对象。数据沿“对象—终端—模组—网络”流动，身份始终跟着对象。这个关系只是教材图 4-19 和图 4-20 的语义合成。

[N013]
在一个只用于说明的设备采集场景中，终端获得运行状态，主控完成必要整理，通信模组把数据送入网络，同时关联设备的工业 ID。这里不代表真实项目、具体网络制式或已完成注册；注册与认证步骤留给下一集。

[N014]
现在可以用一句话收束：通信模组提供“连得上、传得动”的能力，工业互联网终端提供“采得到、处理好、能控制”的能力，工业 ID 则把这些动作锚定到一个明确的工业对象上。理解这三个角色之后，下一集才能继续追问：主动标识载体第一次上电时，怎样完成注册并开始上报。
