## 2. Episode Positioning

- 主解释问题：一个标识载体怎样在有限的附着空间里，同时处理载体与附着物的大小关系、布局、功能、美观、材质、张贴位置和关键信息突出？
- 一句话结论：标识载体设计不是孤立画一个码，而是把载体本身和附着物作为一个整体，根据大小关系、布局、功能、美观、材质与张贴位置组织信息，并让关键内容在真实使用中保持突出、可识别和有秩序。
- 纳入范围：4.1.3 对标识载体设计的定义；载体与附着物的大小关系、布局、功能和美观；根据附着物特点考虑材质和张贴位置；营销、防伪等目的下的关键信息突出；汽车领域圆形与长方形布局示例；专业软件、在线专用设计工具和办公软件排版作为设计手段的边界。
- 排除范围：任何具体尺寸、容差、印刷分辨率、耐磨等级、温湿度等级、胶黏剂型号、码制参数、标准编号、设备规格、软件界面、企业品牌、真实项目验收数据和学习者练习。
- 相邻分集边界：第 35 集负责在材质、工艺、环境和成本约束下选择载体，本集负责选定之后的版式和附着设计；第 37 集负责主动载体与 UICC 的联网和安全边界，本集不提前讨论主动通信；第 33–34 集负责一维码/二维码和 RFID 的机制或比较，本集只把“标识信息”作为版式中的内容层级。

## 4. Content Type and Narrative Strategy

- 主类型：Design explanation（设计说明）。观众需要理解“如何把一个标识载体设计成适配附着物的整体”，而不是背诵一套通用尺寸。
- 次类型：Comparison and selection（比较与选择）。只用来对照图 4-7 的圆形和长方形布局，说明版式是设计决策结果，不建立脱离场景的优劣排行。
- 本集叙事链：现场空间问题 → 一体化设计定义 → 载体形态与附着物关系 → 材质和张贴位置 → 功能与美观并列 → 关键信息层级 → 圆形/长方形教材示例 → 工具边界与设计复核 → 设计结论。
- 问题闭合方式：先说明“有一个码”不等于“载体设计完成”，再用附着物、版式、材质、位置和信息层级逐层约束设计，最后把图 4-7 和工具说明放回“服务整体设计”的结论中。

## 6. Continuous Narration Master Script

以下 N001–N014 为本集唯一可录制口播文字来源。任何后续页面、分镜或备注只能引用这些 ID，不得另写第二份讲稿。

[N001]
在生产现场，一个标签常常要贴到具体的零部件、包装或设备表面。真正的问题不是“把标识放上去”，而是它能不能和附着物的形状、空间以及使用目的一起工作。假设可识别区域有限，标签太大可能影响安装，太小又可能让关键信息不突出。本集要回答：怎样把标识载体和附着物设计成一个整体？

[N002]
教材把这种工作称为标识载体设计。它综合考虑载体本身以及附着物的大小关系、布局、功能和美观，是一种一体化设计。这里的“载体”不只是承载编码的表面，“附着物”也不只是被动的背景；两者的关系决定了标识最终怎样被看到、被使用和被维护。

[N003]
设计不能先画一个孤立的圆或方，再强行贴到产品上。要先看附着物的外形、可用区域和接触关系，再决定载体形态和布局。教材没有给出适用于所有产品的固定比例，关键约束是：版式要服从载体与附着物的关系。

[N004]
这种关系还会影响材质和张贴位置。相同的标识内容，放在平整表面、弧面或包装边缘，设计考虑并不相同；不同附着物的接触方式，也会改变应当选择的材质和位置。这里不需要虚构耐磨等级、温度范围或胶黏剂型号，只需明确：材料和位置是随附着物特点一起决策的。

[N005]
标识载体还承担功能和美观两类目标。教材举到产品营销、防伪等因素，说明载体既要完成标识作用，也可能参与产品呈现。功能层面要让关键信息被注意到，视觉层面要让整体保持秩序和美感；两者不是互相替代，而是同一版式中的并列要求。

[N006]
“关键信息突出”并不等于把所有内容都放大。它更接近一种信息层级：重要内容先被看见，辅助内容保持清楚但不抢夺注意力。教材没有规定统一的字段清单、字号或颜色比例，所以画面和口播都不应补出一套所谓标准模板。

[N007]
图 4-7 给出了汽车领域的标识载体设计示例。左图采用圆形布局，右图采用长方形布局，两者都同时考虑营销和防伪作用。这个图的价值在于展示“同一类设计任务可以有不同版式”，而不是宣布圆形一定优于长方形，或提供一个可直接复制到所有产品的尺寸答案。

[N008]
看这两个示例时，可以沿三层关系观察：载体与附着物的边界、信息和图形在版面的布局、功能与美观如何共同出现。三层关系都成立，设计才不是单纯贴图；只保留一个码而忽略另外两层，后续使用和维护就缺少整体依据。

[N009]
把设计关系画出来，可以形成复核链：先确认对象和附着区域，再检查版式，随后核对材质与张贴位置，最后检查关键信息和整体协调。这是基于教材概念的教学组织，不是认证流程，也不产生自动合格结论。

[N010]
在真实项目中，设计评审还要回到附着物的使用环境。标签是否容易被遮挡、是否与操作面冲突、是否能在维护中保持可见，都要结合对象和位置判断。本集不替项目给出耐久数值，也不把某种材料或位置说成普遍正确；设计要保留证据和现场条件。

[N011]
工具的选择可以不同。教材指出，专业软件、在线专用设计工具以及办公软件排版都可以用于标识载体设计。工具只是把版式关系表达出来的手段，不能代替对附着物、材质、位置和信息层级的判断。本集不演示具体界面，也不把某个软件版本当作课程结论。

[N012]
看到一张精致的标签图时，不能只问“好不好看”。还要追问：它是否和附着物相称，张贴位置是否有依据，关键信息是否有层级，营销或防伪功能是否与整体视觉一致。每个问题都回到同一个设计对象，而不是孤立参数。

[N013]
回到开头的有限空间，合理设计不会先承诺固定尺寸，而是先把对象、附着物和使用目的说清楚，再用版式、材质、位置和信息层级复核。图 4-7 的圆形与长方形只是可见例子；版式来自关系，不来自脱离场景的模板。

[N014]
标识载体设计的起点是共同工作：载体承载信息，附着物提供边界，材质和位置影响稳定使用，功能和美观影响能否被看见和接受。把这些关系组织起来，才算完成设计。具体尺寸、耐久标准和工具操作必须等待证据与项目条件，不能由本集补齐。
