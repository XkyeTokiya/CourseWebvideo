# 用途

用左右两个对照区域和位于主体中的短判据表达边界、差别或尚未跨过的条件，不设置独立底部结论。

# 正例

左右区域分别承载两个状态、对象或能力，pivot 用一个短判据指出读者应依据什么区分两边；标题、两栏和判据共同完成收束，判据不是第三个过程步骤。

# 反例

不要把 pivot 写成长段总结、桥接状态或因果路径；不要增加底部 thesis、断桥、跨栏箭头或胜负式视觉暗示。
