# 用途

在一至两个前提交点已经明确后，集中提出源 A-page 中存在的一个核心问题，用于形成悬念、转向或后续讲解入口。

# 正例

一至两个前提以短标签集中呈现，页面视觉中心只保留一句完整问题；标题负责界定讨论范围，留白强化问题的主导地位。

# 反例

不要把问题拆成选项列表，不要绘制从问题通向答案的路径或箭头，不要提前给出答案暗示；不得把普通陈述擅自改写成源 A-page 中不存在的修辞问题。
