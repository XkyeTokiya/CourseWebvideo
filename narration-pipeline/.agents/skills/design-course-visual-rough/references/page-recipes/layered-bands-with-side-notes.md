# 用途

用无连线的有序文字带表达有限层级，并在侧栏补充观察维度

# 正例

层级只由文字带顺序表达，侧栏使用二到四张短卡

# 反例

不要增加贯穿脊柱、双向通道、能力塔或跨层箭头
