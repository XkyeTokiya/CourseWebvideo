# 用途

用三到四张并列卡表达相互独立、等权或可比较的要点，由论点标题给出共同判断，卡片区域自行完成收束。

# 正例

每张卡只承担一个局部要点并保持结构一致，标题说明这些卡为何被共同呈现；读完最后一张卡即完成本页判断，不再附加 takeaway。

# 反例

不要在卡片下方增加结论条，不要在每张卡内复制同一句小结，也不要为了显示关联增加网络线、断裂电缆或卡片间因果箭头。
