# 用途

用源 A-page 明确提供的时间点或场景设定章节语境，由主标题宣告本页论点，场景图提供具体而克制的现场落点。

# 正例

一个可追溯的年份、阶段或场景标签定格语境，一组短句补充当时条件，主标题直接给出本页判断；场景实景图独立落位，不承担教材证据或读图任务。

# 反例

不要为了制造年代感虚构年份、事件或场景；不要把时间锚点扩展成时间轴、里程碑或演进箭头；不要给场景图叠加标注、读图提示、假界面或不可验证的数据。
