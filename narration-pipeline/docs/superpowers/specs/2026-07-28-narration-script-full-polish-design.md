# 51 集口播稿整体润色设计

## PPT 与任务包兼容版

## 一、目标

以 `outputs/narration-scripts` 下 51 集原始口播为只读基线，在 `outputs/narration-scripts-polished` 中生成并逐篇润色独立副本，使表达更接近面向学习者的自然讲解，减少书面化、审核化和幕后编写痕迹。

教材、课程架构和任务包继续作为事实与制作依据，但不作为口播中的反复叙述对象。

本轮修改只优化口播表达，不改变课程知识结构、事实边界、视觉节拍、分镜映射或下游制作要求。

### 权威关系与生效范围

自 2026 年 7 月 29 日起，本轮润色采用以下目录职责：

* `episodes/**/episode-XX-...-task-package.md` 是 PPT、分镜和媒体制作的冻结基线，只读；
* `outputs/narration-scripts/**` 是润色前原始口播基线，只读；
* `outputs/narration-scripts-polished/**` 是本轮唯一写入目标，完成后作为录制、字幕和成片口播母版。

本设计负责规定口播内容改写标准；`docs/superpowers/specs/2026-07-29-narration-polish-lightweight-skill-v1-design.md` 负责规定轻量执行流程。若旧文档、旧计划或脚本说明仍要求直接修改原始口播、回写任务包或建立复杂状态机，以本节和轻量 V1 设计为准。

---

## 二、核心原则

本轮工作属于“受约束的口播层改写”，不是重新创作讲稿。

润色后的文本必须同时满足以下要求：

1. 听起来像自然讲解；
2. 表达的事实与原稿一致；
3. 每个 N 段继续承担原来的教学职责；
4. 与既有 PPT、分镜和视觉揭示顺序保持兼容；
5. 不引起时长、字幕和动画节奏的明显漂移。

---

## 三、修改范围

每份润色稿先从对应原始口播逐字复制，再仅修改润色副本中从 `[N001]` 到最后一个 `[Nxxx]` 的连续口播正文。

必须保持：

* 全部 N 段数量不变；
* N 编号不变；
* N 段顺序不变；
* 每个 N 段的段落边界不变；
* N 段之外的全部字符不变。

不得修改：

* 标题、集号和模块信息；
* 来源任务包；
* 时长估算；
* 视觉留白和操作留白；
* Storyboard、beat、media 和 evidence 映射；
* 图片提示词；
* 制作约束；
* 验证报告；
* 任何其他非口播内容。

---

## 四、必须保护的五层内容

### 1. 结构层

必须保持每集原有的 N 编号序列、段落数量、段落顺序和段落边界。

不得合并、拆分、新增或删除 N 段。

### 2. 语义职责层

每个 N 段必须继续完成原来的教学任务。

例如，原段负责开场提问，就不能改成知识总结；原段负责引出某一概念，就不能让这一概念提前在上一段完整出现；原段负责相邻分集交接，就必须继续承担交接功能。

允许调整段内句子顺序，但不得把核心知识点移动到其他 N 段。

### 3. 视觉锚点层

所有与 PPT 或分镜相关的关键词、对象和关系，必须继续保留在原 N 段中。

包括但不限于：

* 首次出现的专业概念；
* 画面需要逐项展示的清单；
* 图示中的关系方向；
* 案例对象；
* 数字、分类和层级；
* 前后对比；
* 相邻分集边界；
* 需要与动画同步出现的总结语。

不能因为消除重复，就删除画面所依赖的口播锚点。

### 4. 事实、结论与必要限定层

保留原稿中会直接影响知识含义的内容，包括：

* 事实与定义；
* 专业术语；
* 数字、年份、周期和数量范围；
* 条件与适用对象；
* 因果和责任关系；
* 案例的适用范围；
* “建议”“可能”“相对”“根据业务规模扩展”等必要限定；
* 对当前讲解结论成立范围的必要说明。

不得把建议改写为强制要求，把定性比较改写为定量结论，把案例结果扩大为行业结论，也不得新增现有资料没有提供的知识。

原稿中仅用于约束编写者、防止后续扩写、列举资料缺口或声明禁止生成内容的句子，不属于需要保留的口播事实。此类信息应继续保留在任务包的证据台账、事实边界、制作约束和验证报告中，原则上从口播正文直接删除。

判断标准是：

> 删除后是否会改变学习者对本集知识的理解。

如果不会改变知识含义，只是减少了对资料来源、缺失字段或禁止扩写事项的说明，就应删除；如果删除后会把建议变成要求、把特定案例变成普遍结论，或改变数字和条件的适用范围，则必须保留相应限定。

### 5. 时长层

润色后应保持原有信息量和讲解节奏。

原则上：

* 单段字符量不宜发生大幅变化；
* 单集正文字符量建议控制在原稿的约 ±10% 范围内；
* 含受保护数字、清单或分镜同步内容的段落，变化应更加谨慎；
* 因删除“教材指出”等元叙事造成的缩短，可以通过自然解释和转场补足，但不能加入新知识。

字符比例只作为异常检测指标，不代替人工审校。

## 五、允许修改的内容

可以进行以下改写：

### 1. 消除幕后编写语言

将以下表达转化为直接讲解：

* “教材指出……”
* “教材列出……”
* “教材用……说明……”
* “教材没有给出……”
* “根据教材，本集……”
* “这是教材的组织化总结……”

修改后，口播正文中的“教材”应为零次。

### 2. 优化书面表达

可以：

* 缩短过长句子；
* 将复杂复句拆成适合口播的短句；
* 减少连续并列名词；
* 将被动表达改成主动表达；
* 用自然指代减少机械重复；
* 增加必要的承接句；
* 调整标点，使停顿更符合口语节奏。

### 3. 删除不属于教学内容的审核说明

原稿中的事实边界需要在任务包中完整保留，但不要求全部进入口播。

以下内容若只用于约束编写和制作，原则上直接从口播正文删除，不改写成面向学习者的提醒：

* “教材没有给出……”；
* “本集不补充……”；
* “不能添加……”；
* “不得据此推导……”；
* “不能虚构……”；
* “不生成……”；
* 对报告模板、接口字段、提交入口、处罚流程等资料缺口的罗列；
* 对后续 Agent 或制作人员的操作禁令；
* 对证据状态、核验状态和来源完整性的说明。

例如：

原表达：

“教材未给出报告模板、字段格式、阈值或提交入口。”

处理方式：

直接删除该句，只保留已经确认的报备周期和信息类别。

原表达：

“不能据此虚构可用性、故障次数、响应时限、排名或奖金。”

处理方式：

直接删除该句，只讲各类报告信息分别反映什么运营状态。

不得为了保留审核信息而改写成：

“具体模板和提交方式需要根据实际要求确认。”

除非“需要根据实际要求确认”本身是本集必须教授的知识，否则这种表达仍然属于资料说明，不应进入成片口播。

### 4. 保留会改变事实含义的限定

不能把所有边界信息一并删除。以下内容属于事实本身，应保留并自然融入讲解：

* “建议”而不是“要求”；
* “每月”而不是“定期”；
* “至少 2–3 名”及其数量范围；
* “根据业务规模扩展”；
* “在该案例中”；
* “可能”“相对”“通常”等表示结论强度的词；
* 来源年份或文件名称在承担版本归属时；
* 某结论只适用于特定对象、阶段或条件的说明。

例如：

原表达：

“AII2022 建议每类岗位至少 2–3 名核心人员，并根据业务规模扩展。必须保留‘建议’和‘按规模扩展’，不能改写成统一编制。”

润色后：

“AII2022 建议，每类岗位至少配置 2–3 名核心人员，并根据业务规模进行扩展。”

其中后一句审核警告删除，但“建议”“2–3 名”和“根据业务规模扩展”必须保留。

### 5. 删除审核说明后的衔接修复

删除审核句后，应重新检查段内和段间衔接，避免留下突兀转折、残缺指代或失去落点的句子。

可以进行以下修复：

* 调整同一 N 段内的句子顺序；
* 补充不含新知识的承接语；
* 将上一句的结论作为本段落点；
* 让下一段直接承接当前教学问题；
* 删除因审核句移除而失去作用的“但”“因此”“这里”等连接词。

不得用新的资料缺口说明来填补删除后的篇幅，也不得因为段落变短而补充未经支持的知识。

## 六、需要条件判断的修改

以下修改可以进行，但必须确认不会影响 PPT 和任务包映射。

### 1. 段内调整句子顺序

仅限同一个 N 段内部。

调整后必须保持该段核心概念的首次出现位置、画面揭示顺序和总结落点基本一致。

### 2. 增加提问句

只有在原段本身承担引入、转场或总结职责时，才可以加入简短问题。

不得新增需要学习者暂停、回答、讨论或完成任务的课堂活动。

### 3. 增加场景化表达

只能使用原稿、任务包或既有案例中已经存在的对象和场景。

不得自行加入新企业、新行业、新角色、新政策事件或新数据。

### 4. 合并重复解释

只能合并同一 N 段内部的重复信息。

若相邻两段分别对应不同视觉节拍，即使内容相近，也不得跨段合并。

### 5. 改写专业术语

受保护术语本身应保留。

可以在术语前后加入自然解释，但不得使用含义较宽、较窄或带有额外政策含义的近义词替换。

---

## 七、禁止修改的内容

不得进行以下操作：

1. 移动知识点到其他 N 段；
2. 提前或延后专业概念的首次出现；
3. 改变原有知识顺序；
4. 删除 PPT 画面需要呈现的关键词；
5. 改变清单项目数量；
6. 改变关系图中的角色、对象或箭头方向；
7. 改变数字及其归属；
8. 删除“建议”“可能”“相对”“根据规模”等限定语；
9. 将历史版本、文件建议或教材口径改成当前强制要求；
10. 新增资料之外的事实、案例、政策、标准或数字；
11. 改变相邻分集的内容边界；
12. 新增练习、测验、课堂互动或学习任务；
13. 修改 N 段之外的任何内容；
14. 为追求口语感而降低专业准确性；
15. 为追求完整性而补写任务包明确排除的内容。

---

## 八、“教材”及事实边界表达的处理方式

不能对“教材”进行机械删除或统一替换。应先判断整句话在口播中的功能，再采用以下三种处理方式。

### 类型一：来源提示，但内容本身需要保留

原句：

“教材给出自行运营或委托运营两种选择。”

改写为直接讲解：

“二级节点可以自行运营，也可以采用委托运营的方式。”

删除来源提示，保留知识内容。

### 类型二：来源或版本本身属于必要限定

原句：

“教材引用《工业互联网标识解析二级节点建设指导》（AII2022）的建议：每类岗位至少 2–3 名核心人员，并根据业务规模扩展。”

改写为：

“AII2022 建议，每类岗位至少配置 2–3 名核心人员，并根据业务规模进行扩展。”

删除“教材引用”的幕后叙事，保留来源年份、建议属性、数字和适用条件。

### 类型三：仅用于防止扩写或声明资料缺口

原句：

“教材没有给出模板、字段格式、阈值或提交入口。”

处理方式：

从口播中直接删除。

原句：

“不能据此虚构可用性、故障次数、响应时限、排名或奖金。”

处理方式：

从口播中直接删除。

此类信息继续保留在任务包的事实边界、制作约束或验证报告中，不需要转写为“具体内容需要结合实际确定”等学习者提示。

### 类型四：课程范围与分集交接

原句：

“本集不展开第 46 集的安全细节。”

可改写为自然的课程交接：

“这一集先聚焦持续运营，具体的安全保障将在下一集展开。”

只有当范围说明能够帮助学习者理解当前知识结构或完成上下集衔接时，才保留在口播中。单纯面向编写者的排除范围应删除。

## 九、单集处理流程

每一集必须作为一个完整单元处理，不得采用跨文件的全局替换。

### 第一步：读取任务包约束

在润色正文前，先确认：

* 本集主解释问题；
* 一句话结论；
* 纳入与排除范围；
* 受保护术语；
* 受保护数字；
* 相邻分集边界；
* N 段与 beat 的映射；
* 视觉揭示顺序；
* 下游制作约束。

### 第二步：标记每个 N 段的职责

为每段建立内部标记，例如：

* 开场；
* 问题提出；
* 概念定义；
* 条件解释；
* 案例；
* 数字边界；
* 视觉清单；
* 阶段总结；
* 全集收束；
* 下集交接。

该标记只用于润色过程，不写回最终文件。

### 第三步：区分三类边界信息

在逐段润色前，将原稿中的边界表达分为三类：

#### A 类：事实必要限定

删除后会改变事实含义，必须保留。

例如：

* 建议；
* 每月；
* 至少 2–3 名；
* 根据业务规模扩展；
* 在该案例中；
* 可能、相对、通常；
* 版本或年份归属。

#### B 类：学习范围提示

只有在帮助学习者理解本集结构、上下集关系或概念边界时才保留，并改写为自然讲解。

例如：

* 本集聚焦持续运营；
* 安全保障在下一集展开；
* 这里讨论的是责任分工，而不是部署方式。

#### C 类：幕后审核与制作约束

直接从口播删除。

例如：

* 资料没有提供哪些字段；
* 不得新增哪些数字；
* 不能虚构哪些结果；
* 当前版本没有核验；
* 不补充哪些机构、流程或模板；
* 对后续 Agent、PPT 或制作人员的限制。

分类结果只用于内部润色，不写回口播正文。

### 第四步：逐段润色

逐段处理时，按以下顺序执行：

1. 保留本段事实、术语、数字和必要限定；
2. 删除来源提示和 C 类审核信息；
3. 将需要保留的 B 类范围说明改成自然讲解；
4. 优化句式、节奏和段内逻辑；
5. 检查删除后是否影响 PPT 需要的关键词和视觉锚点；
6. 不通过新增知识或新的资料说明补足篇幅。

### 第五步：整集连续复读

重点检查：

* 开场是否自然；
* 段间是否能够连续听懂；
* 是否存在重复结论；
* 是否连续使用相同句式；
* 是否突然切换对象；
* 代词指向是否清楚；
* 结尾是否回应开场；
* 下集交接是否自然。

### 第六步：与任务包反向核对

完成口播润色后，逐项核对：

* 每个 beat 所需信息是否仍在对应 N 段；
* 视觉首次揭示是否仍然成立；
* 图表清单是否完整；
* 相邻分集边界是否保持；
* 受保护术语、数字和限定是否仍在；
* 是否误增任务包排除内容。

## 十、自动校验项目

每集润色完成后，应至少进行以下机械校验。

### 1. N 编号校验

润色前后的 N 编号序列必须完全一致。

### 2. 段数和顺序校验

段落数量、编号顺序和段落边界必须一致。

### 3. 非正文差异校验

N 段之外的文件内容应逐字符一致。

### 4. 幕后语言校验

N 正文中“教材”出现次数必须为 0。

同时搜索以下高风险表达：

* “本任务包”；
* “来源台账”；
* “证据边界”；
* “教材未给出”；
* “本集不补”；
* “不能添加”；
* “不得据此”；
* “不能虚构”；
* “不生成”；
* “未另行核验”；
* “版本未指定”。

出现这些表达时，应人工判断：

* 若属于幕后审核、资料缺口或制作约束，直接删除；
* 若包含事实必要限定，只保留会改变知识含义的部分；
* 若承担上下集交接或学习范围提示，改写为自然讲解。

校验目标不是把这些词替换成另一组委婉说法，而是确保不属于教学内容的审核信息不再进入口播。

### 5. 数字校验

提取润色前后全部数字及其所在 N 段。

数字应保持一致，包括：

* 整数；
* 小数；
* 百分比；
* 年份；
* 范围；
* 周期；
* 数量单位。

不能只比较全篇数字集合，还要比较数字所属的 N 段。

### 6. 术语校验

对任务包中的受保护术语建立单集词表，检查润色后是否仍然存在，或是否采用了经人工确认的等义表达。

### 7. 字符量校验

计算：

* 每段字符变化率；
* 每集总字符变化率；
* 极端缩短段；
* 极端扩写段。

异常段必须人工复核。

### 8. 段外溢出校验

检查某个关键词是否从原 N 段移动到其他 N 段，尤其关注分镜首次揭示内容。

---

## 十一、人工验收标准

每集至少进行三轮人工检查。

### 第一轮：事实与边界检查

确认：

* 事实、数字、定义和结论没有变化；
* “建议”“每月”“根据业务规模扩展”等必要限定仍然存在；
* 案例没有被扩大为普遍结论；
* 没有新增资料之外的内容；
* 仅服务于编写审核的资料缺口和禁止扩写说明已经移出口播；
* 删除审核说明后，口播没有暗示原资料未支持的具体结论。

### 第二轮：教学口播检查

重点检查：

* 是否仍在向学习者解释“资料没有提供什么”；
* 是否仍在罗列不允许生成的内容；
* 是否频繁出现“不能”“不得”“不补充”等审校口吻；
* 每句话是否都在帮助学习者理解本集知识；
* 删除审核句后，段落是否仍然完整、自然；
* 是否为了维持篇幅而加入了空泛说明。

判断原则是：

> 一句话如果主要用于提醒编写者不要犯错，而不是帮助学习者理解知识，就不应留在口播中。

### 第三轮：PPT 兼容检查

对照 storyboard 和 visual intent，确认：

* 画面出现时有对应口播；
* 口播首次提及时画面可以同步揭示；
* 清单数量与画面一致；
* 视觉总结与口播结论一致；
* 没有因为润色导致动画提前或滞后；
* 没有要求 PPT 增加新画面。

---

## 十二、交付要求

最终修改写入 `outputs/narration-scripts-polished` 下对应 Markdown 文件的 N 正文区域。`outputs/narration-scripts` 下原始口播和 `episodes` 下任务包保持逐字符不变。

同时生成一份批次校验记录，至少包括：

* 文件名；
* 原 N 段数量；
* 新 N 段数量；
* “教材”剩余次数；
* 原正文字符量；
* 新正文字符量；
* 字符变化率；
* 数字校验结果；
* 受保护术语校验结果；
* 非正文差异校验结果；
* 人工复核状态；
* 特殊调整说明。

特殊调整说明只记录高风险修改，例如：

* 保留了某一来源年份；
* 将审核式缺口表达转为自然边界；
* 为保持 PPT 同步而保留了看似重复的关键词；
* 某段因删除大量元叙事而出现较明显缩短。

---

## 十三、验收标准

整批完成后应满足：

1. 51 份文稿均完成整体润色；
2. 各文件 N 编号序列完全一致；
3. 各文件 N 段数量、顺序和边界不变；
4. N 正文中的“教材”出现次数为 0；
5. 润色稿 N 段之外的全部内容与对应原始口播逐字符一致；
6. 每个 N 段的原有教学职责保持不变；
7. 与 storyboard、media 和 visual intent 的语义映射保持有效；
8. 原稿中的数字、术语、条件、版本和必要限定没有缺失；
9. 仅用于防止扩写、声明资料缺口或约束后续制作的内容已从口播中删除；
10. 没有把审核说明改写成“需要结合实际确认”等新的委婉审核腔；
11. 未新增现有资料不支持的知识；
12. 未将建议扩大为要求、案例扩大为普遍结论；
13. 未改变相邻分集边界；
14. 未产生生硬删句、残缺指代、固定替换腔或段间逻辑断裂；
15. 正文字符量没有异常波动；
16. 连续朗读自然，每句话都具有明确的教学作用；
17. 不需要同步修改现有 PPT、分镜或媒体计划。

---

## 十四、非目标

本轮不进行：

* 课程知识结构重写；
* N 段重新划分；
* 教学案例扩充；
* 事实核验更新；
* 现行政策补充；
* PPT 修改；
* 分镜修改；
* 字幕制作；
* 画面脚本修改；
* 图片或动画制作；
* 音频录制；
* 时长预算更新；
* 任务包任何章节更新；
* 原始口播基线修改。

若润色过程中发现原口播与任务包存在事实冲突、段落映射错误或明显制作矛盾，应单独记录问题，不在本轮中自行修复任务包。
