## 实施边界

以原章节为基础保留用户选中画面的主要视觉结构和状态推进，章节代码独立复制到 `episode-design-reference`，不更改 ep06、ep35 原集或正式 inputs。共享播放器和 `active-identification-note` 主题不变。对独立观看需要的少量衔接文字作调整并在实例 README 记录；不合成音频、不录屏。

源码可在不改变画面行为时做局部简化和等价 token 替换，不能为了减少代码把用户选中的构图和演示改成另一套。参考索引按关系定位到单章，避免每次通读两期全集；是否固定为默认强制参考及实际 token 消耗，待成品审阅和后续制作验证。

## 验证

核对 5 章 / 17 beats、源素材、视觉状态与画面；播放中逐步推进、回退、直接跳转和刷新恢复。定向运行 `pnpm audio:extract -- --episode episode-design-reference`，并执行实例检查、类型检查、共享 lint 与完整构建。
