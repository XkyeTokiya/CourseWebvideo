# Episode 05 图片生成提示词

主题：对象身份锚点。所有图片为 16:9 横向写实工业纪实摄影，匿名化工业现场，强调对象身份与跨主体信息连续性，不显示真实系统或可读数据。

## M001｜收货人员扫码核验包装标签

**提示词**

16:9 横向写实工业纪实摄影，企业收货区，一名收货人员用手持扫描设备核验带有普通工业标签的包装箱，包装、零件和收货台真实可见；扫描动作已经发生，但现场仍需要进一步确认对象身份和跨企业信息，画面表达“扫码成功不等于身份已经跨主体到达”，不显示扫描结果、可读编码或软件界面，人物自然、光线真实、匿名化。

**负面提示词**

品牌 Logo、可读标签、二维码、条形码、扫描结果、软件界面、数据大屏、网络箭头、夸张成功姿势、科幻效果、卡通、海报、信息图、水印、乱码。

## M002｜物理对象与数字身份的映射

**提示词**

16:9 横向写实工业纪实摄影，制造车间中产品、工业装备和制造设备同时处于工作环境，工作人员正在把一件具体物理对象与现场记录进行核对；画面通过同一对象、标签位置和工作人员的确认动作表达物理对象与数字身份之间的映射关系，不画抽象数字人、不显示软件界面或可读编号，现场真实、克制、匿名化。

**负面提示词**

品牌 Logo、可读文字、可读编号、二维码、条形码、悬浮信息卡、数字孪生人、网络连线、科幻蓝光、卡通、海报、信息图、水印、乱码。

## M003｜教材图 1-4 身份映射

**提示词**

严格使用或提供教材图 1-4 的原始图像，不进行文生图替代，不重绘、不补画、不改写图中文字、不改变原图结构、箭头、颜色和标注；保持教材原图完整，用于说明同一对象跨研发、生产、物流、销售等环节保持同一身份。若原图不可用，只输出“等待教材原图”，不要生成替代版本。

**负面提示词**

文生图替代、AI 复刻、重新设计、重新排版、删改文字、补画节点、改变箭头、改变颜色、虚构环节、模糊标注、裁切关键内容、品牌 Logo、水印、乱码。

**提示词**
