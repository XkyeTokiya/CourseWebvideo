# Canonical handoff script

## A001 · 锚点页

先确认共同锚点。

## A002 · 职责页

有了共同锚点，

---

再把两个主体放进同一场景，看清各自承担的职责。

## A003 · 原图页

教材原图把这层关系完整保留，读图时先看对象，再看它们如何共同支撑结论。

## A004 · 记录页

当信息来自不同记录时，先按共同标准并列整理，再比较它们分别回答的问题。

## A005 · 场景页

到了具体场景，时间和地点先把讨论范围固定下来，图片只负责提供现场落点。

## A006 · 判据页

两个状态看起来相近，真正的区别不在名称，而在它们是否满足同一个判断条件。

## A007 · 步骤页

最后把步骤按阅读顺序收束，结果必须来自前面的动作，不能凭空增加新的价值判断。
