# EP02 视觉粗设

## 1. 单集视觉策略

- **受众与目的**：面向工业互联网通识学习者，先让“已经联网却没有改善”的矛盾成立，再依次建立四体系职责、物理与数字协同、双向信息机制和业务落点，使学习者最终能判断闭环何时真正形成。
- **默认载体**：以问题聚焦、并列卡片、无连线分层文字带、左右对照和单向步骤为主；页面关系只用顺序、分组、对照和阅读终点表达，不把语义项机械画成节点或箭头。
- **图片策略**：Q=ceil(15/3)=5；图片页为 A001、A004、A011、A014、A015，依次使用 M001–M005。五项均为互不复用的实景 AI 媒体需求，实际资产在 PPT 结构完成后解析。
- **逻辑图策略**：全篇使用零页逻辑图；本集的上行、下行与再次反馈均可由线性步骤、并列职责和文字结论准确保留，无需申请受限逻辑配方。
- **内部信息**：A/V/R/M/E ID 仅供核对，不上屏。
