- Kickoff gate:正式输入集恰好是三个只读冻结源(a-page.json、visual-rough.md、approved-spoken-text.txt),任一缺失或 approved_text 不可解析即停并报告,绝不降级到通用 article 流程;用根级 `pnpm episode:new -- --id <ep> --title 「课程主题式标题」 --theme <theme>` 建实例,只把三个正式输入拷入 episode 目录(随包验证 JSON 留在后面),源 task-package 目录绝不修改。Confidence: 0.9
- Phase 1 同轮双交付后硬停:script.md 从 pages[].nx 无损派生(批准文案不动,只加 --- 拍分隔符 + 节标题),outline.md 含 top scale stats + 全 episode 视觉调度表,先通用 outline 自检再 Courseplay 场景连续性协议(review_mode: self);包内无媒体文件时 outline 保留视觉粗设 M-id 并标 placeholder/待提供,可用的本地占位图素材库固定为 `player/占位图/16-9/` 与 `player/占位图/4-3/`,它只提供构图占位而不是事实证据或正式媒体;episode:new 后立即替换模板占位元数据(entry.tsx 真 episode id + 课程主题式标题;article.md 改写为画面信息源说明或按惯例删除);首轮实现时填 src/data/cover.json 课程元数据草稿并显式标注假定字段请用户确认;以 Checkpoint Plan 收尾(四计数:Base scenes / Accent frames / Custom scenes / Narration beats),等一次确认再进 Phase 2。Confidence: 0.85
- 隔离章契约:a_page.nx 是口播权威,narration.beats 是唯一允许的拍视图——narrations.ts 逐项原样复制(不改写、不重切、不增删);拍/步生成用语义(结构锚定)切分而非时间启发式:默认数量是单一确定值,每个偏差都是引用触发条件的文档化例外并内联标注,用汇总偏差统计审计;每章一个连续 base-scene,step 推进内容/焦点/关系而非机械换页;accent 步按 packet 规定组件切换,base-scene 不得重复 accent 判断;缺素材严格按 packet 占位资格处理,绝不搜索/生成替代证据;获准使用本地占位图时,按画幅从 `player/占位图/` 选文件并复制到 `episodes/<id>/src/chapters/<chapter>/assets/` 后由组件本地导入,禁止符号链接/目录联接、禁止从章节直接跨目录引用素材库,后续正式媒体在章节 assets 原位替换。Confidence: 0.85
- Outline 元数据与工具解析契约冲突:修数据不修契约——handoff 生成/校验失败先 grep 工具源正则定位根因;映射/计数行严格满足契约(A-page 行须以 `Axxx` 结尾、step 时长注记用半角 `(~10s)`;工具自身 heading 全角/step 行半角口径不一时,以工具正则为契约基准);附加语义注记(如 callback)做信息移位挪独立行,绝不删改已批准文案、绝不反向改工具迁就数据;批量元数据规范化写 scratchpad 脚本一次替换并输出 before/after 计数对账;计数陷阱(用户纠正):outline.md 素材清单小节同样含 `### Axxx` 标题(带媒体的页),绝不把 grep 命中的标题当章节列表——progress.total 等计数一律完整 read outline.md 后按章节小节/视觉调度表推导(episode-04 曾凭 grep 误写 total=3,用户纠正为 A001–A008 共 8)。Confidence: 0.8
- 滚动审查簿记(chapter-review/rolling-v1):pending 登记后任何源码改动都使 source hash 失效——修复/采纳建议后统一重算 hash 再登记;attempt 文件不可变追加:must-fix 原报告保留,修复后补 recordedBy:self 验证 attempt,runtime.json 把旧 attempt 记 superseded(resultStatus: reported-late);契约审查 subagent 后台并行派发,本地同时跑构建/簿记不空等;self 验证 ≠ 终验,交付报告明示 self 验证状态、以用户视觉验收为最终关口;超协议状态(如多章 pending 突破模式 A 单 pending 上限)主动披露并附消除路径;簿记文件缺失(如 P1 漏建 review-summary.json)先读契约源(tools/*.mjs)确认期望 schema,补最小合法初始状态使验证链绿并在接续确认中披露,不改工具绕过验证。Confidence: 0.8
- 实例状态簿记同步:开工即把 project.json `status` 切到实际阶段(planned→in-progress),不留"待制作"旧态——用户会抓簿记滞后;合法取值先从 validator 源(validate-episodes.mjs)+ sibling 实例现状推导再写,不凭猜测;契约门控字段(rolling-v1 `current` 须对应 settled/已登记 pending,而 pending 登记要求正式章目录+entry.tsx 注册)在隔离期保持最小合法态(`current: null`),完整值留到门控事件(验收迁移+pending 登记)同轮落,并在汇报中说明该口径;每次状态改动后重跑 episode:check 确认绿。Confidence: 0.8
- 标题省略授权(实验性、仅删除性):语义冗余的论点标题可在 outline 层省略——可见标题: `none` + 必填省略理由,核心判断保留为 outline 元数据;章代理严格执行 outline 声明,无新增判断权;"省略后观众仍能从当前既有画面完整得到同一判断"必须为明确 yes,有疑即保留;在 1-2 个 episode 试点记录哪些页通过/不可省略(标题是唯一判断载体的页)后再谈扩展。Confidence: 0.85
- 风格参考 episode 取用序与参考边界:新实例章节开发的风格参考默认用 episode-35(用户指定为本期基准),用户显式指定的实例永远优先,绝不按"最近完成/最新"等启发式自行挑选;参考边界是只深读单一完整 exemplar 章(tsx/css/narrations 全量)+ 契约文件(entry.tsx 注册接法、outline 字段口径),刻意不广读其余 sibling 章——视觉多样性来自让 agent 只对齐机制(states 数组+`?? last` 兜底映射、`--x-i` stagger 变量、data-tone/data-on 状态属性、card-glass 判断 plate、CSS keyframes+animation-delay calc)而非对齐样子。Confidence: 0.85
- 上屏 guidance 用法(用户定规,已明文重申):tag 式上屏的根因就是把 `episode-04-a-page.json` 的 screen 字段(S/G 上屏内容组条目,handoff 投影为 packet 的 screen_guidance)机械映射为屏上组块——用户明文定规:a-page 的 screen 只是内容方向参考项,不是逐条落屏清单,下游必须综合三源(screen_guidance + narration.beats + presentation)重新设计完整上屏内容;禁止按 G/S 分组机械映射成屏上组块、tag 或一 S 一块,且不保留 guidance 的清单结构(把 chips 换成箱体/列表行的"换皮"重做因信息组织仍按 S/G 分块,被判"治标不治本");skill 标注为"参考项/可选"的字段从设计阶段起就按参考对待,绝不把参考当逐条清单。Confidence: 0.95
- Outline 章设计块权威(R3/R4 验收裁定):outline.md 每页的设计要求是章实现的硬约束——可见标题声明(如 S010/S014"可见标题: 保留")与结构指纹(如 A003 `steps ×2 | terminal-result`、A004 `parallel-cards ×3` 等权三卡 `equal-weight-accumulation`)必须原样落成屏上结构;screen_guidance 三源重组只发生在 outline 声明的槽位内部,不得以"脱离 S/G 结构"为由丢掉标题区或把等权三卡改成横向流水线——用户裁定此偏离为"本质上没有重做,完全偏离 outline 设计要求,验收不通过";弃 guidance 结构 ≠ 弃 outline 结构,handoff packet 对 outline 只带哈希不带章设计块内容,章制作前必须直接读 outline.md 本章设计块。Confidence: 0.9
- 工具投影防诱导(设计缺陷倾向,修复方向待用户裁决):agent 层错误要继续追因到工具对上游参考数据的投影方式——用户会追问"这是否是设计缺陷";须分层如实诊断:"规范缺口"(限制条款是否覆盖实际在用的字段,本例 screen_guidance 已被禁止机械对应条款 + usage_policy:reference 覆盖)与"工具设计陷阱"(a-page screen 的 G/S 清单结构逐条原样搬运进 packet,天然诱导按组落块/按条落 tag)可同时成立,契约文本已写 ≠ 无设计缺陷;参考数据的更优投影是信息移位而非结构搬运(压缩为整页内容方向摘要 + 事实边界,或字段级显式反逐条警示);修复按"只修实现 / 改工具投影 / 两者都做"给选项等用户裁决,契约层改动不自行动手。Confidence: 0.7
