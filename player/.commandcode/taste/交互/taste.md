# 交互
- 长文件按可验证段落逐段落盘,每段完成即检查连接点与文件状态;中断后只从已落盘成果继续,不得把未落盘思考声称为已完成。Confidence: 0.95
- Checkpoint 只列真正需要用户决定的编号项,相邻项可合并回答;用户未回应的非决策说明按原方案保留,但未回应的硬门禁不得视为已授权。Confidence: 0.9
- 轻中断用“已完成/确切中断点/下一步”三项短报;存在写操作、异常或流程偏离时再补充未完成事项、环境、验证状态和恢复顺序。Confidence: 0.85
- 用户以设计模式提供 Element、Selector、计算样式或屏上文本时,先据此定位章文件并核实根因;“删除所有类似项”须在获准范围内扫描整类模式,同时保留事实护栏和 alt 描述。Confidence: 0.8
- 代码级检查通过后提供播放 URL、目标章节/step 与验收重点并停下;最终视觉验收归用户,除非用户明确授权 Agent 使用浏览器排查或修复视觉问题。Confidence: 0.95
