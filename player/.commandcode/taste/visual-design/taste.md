# Visual Design
- 每章围绕一个与内容关系直接对应的视觉主体组织舞台,让观众看见机制、变化或关系在发生;纯标题、判断条和文字卡片堆叠不能作为完整章节。Confidence: 0.95
- 视觉参考按“用户指定的完整 exemplar > 当前主题 token/primitive > 域 skill”取用;只深读一个完整 exemplar 与注册/outline 契约,对齐机制而不抄外形,不得用通用设计指南覆盖仓库约束。Confidence: 0.9
- 反对的是无差别重复同一种信息组织,不是禁用某个组件;相邻章应改变主构图、视觉权重或关系表达,但不得为求差异而背离 outline、改写口播或新增事实。Confidence: 0.95
- 页面不设置跨章固定 kicker、页码、masthead、标题槽、底栏或判断条 chrome;标题与收束区按本页信息关系决定,同一判断在一屏只保留一个清晰载体。Confidence: 0.95
- 上屏内容优先转化为图形、路径、媒体阅读、结构变化或状态演示,文字只承担必要标签和短句;不得用 tag/chip、等尺寸小卡或换皮列表机械承载全部关系。Confidence: 0.95
- 范围边界句、制作术语、约束说明和 silent constraints 不上屏;屏上事实与文案只能来自当前获准内容源,缺素材用轻量 placeholder 明示,不编数字、logo 或装饰性伪信息。Confidence: 0.95
- 揭示顺序服从口播:前提先建立,关键判断和强调后出现;并列项最终保持等权,顺序项才呈现进行态,图片持续阅读时保持媒体不反复卸载。相邻元素的 stagger 应保持紧凑:普通间隔参考 120–240ms,需要明确辨认顺序时可放宽到 240–360ms,默认不超过 400ms;普通拍内动画链尽量在 1.2–2s 内收完,复杂判断链不宜超过约 2.4s。因口播报到点而设置的较长绝对延迟不算 stagger,锚点后的元素仍按紧凑间隔展开;实例数值只作调试参考,不得固化为跨章硬阈值。Confidence: 0.95
- 视觉反馈先定位节奏、内容、布局、状态或代码层,再修改最小切片;修复一个已确认的机制缺陷时同步扫描当前授权范围内的同类模式,但不越界修改已冻结 episode。Confidence: 0.9

# 已验证视觉模式
- 舞台内容必须落在主题安全区内:根舞台或等价容器消费主题 token 的边距,全屏 scene 也不得贴画布边缘;具体 primitive 可随配方变化,不把单一 class 当唯一实现。Confidence: 0.95
- 垂直构图以主内容或媒体区主导视口为目标,可参考约 75–80% 高度;短 takeaway 可参考约 84px。主区低于约六成且单句压满下半页不合格;收束时让主构图轻微退让。Confidence: 0.9
- 结尾句可用媒体区上的深色 scrim 与大字呈现,不另建白色底卡;晚现元素从首拍占据稳定槽位再以 opacity 显示。收束与序列末项重合时,让末项承担 endpoint,避免重复判断条。Confidence: 0.9
- ghost 槽标签与实际内容同时保留在 DOM,通过 opacity/visibility 做真正 cross-fade,并让内容略晚进入;禁止用 `display:none` 到 `block` 的硬切替代状态过渡。Confidence: 0.9
- 等权卡组使用一致内部骨架:顶部 kicker、主概念在 `flex:1` 中居中、底注锚定分隔线;仅信息层级确有差异时分化。空卡不得新增文案,优先恢复 sourced copy,或用分布、字号权重与弹性 gap 消化空间。Confidence: 0.9
- 列表夹在固定头部和底部收束之间时,可用 `flex:1`、`min-height:0`、`space-evenly` 将空白分散到条目间,避免条目挤作一团而剩余空间集中成死区。Confidence: 0.9
- 晚拍元素覆盖常驻内容时先计算预留槽从首拍起占用的纵向预算,检查 padding、gap、字号和演示槽总和,不要先用 z-index 掩盖;逐块收紧到各步不溢出并保留零回流槽位。Confidence: 0.9
- 完全相同的重复形状即使增加身份标签也可能无法表达差异;图形自身无可读语义时,保守删除优先于继续加文字。用户明确要求删除时可接受局部退化为文字承载,“每章必须有视觉演示”不得反过来否决该决定,但须在交付报告披露张力。Confidence: 0.9
