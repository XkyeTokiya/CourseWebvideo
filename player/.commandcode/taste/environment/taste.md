# Environment
- Windows shell/git 细节:shell_command 执行 cmd.exe——多路径 Copy-Item 等 PowerShell cmdlet 走 powershell 工具;git 多行提交信息安全写法:两个 -m 标志、scratchpad 文件 + `git commit -F <file>`、或 here-string 管入 stdin(`@'...'@ | git commit -F -`);here-string 位置传参会被静默当 pathspec 导致提交失败,bash 风格 heredoc(`git commit -F - <<'EOF'`)在 cmd 同样不支持——多行提交信息用 scratchpad 文件 + `commit -F`;cmd 无 tail/head 等 Unix 工具——`| tail` 管道直接失败,长输出直接跑命令(靠工具自身截断)或走 powershell 工具;长输出的过滤/汇总可用 node -e 管道一行流(如测试输出提取 pass/fail 行、截 stderr 尾部摘要);文本计数/切分用 PowerShell/git 原生命令;findstr 匹配中文模式会静默失配(cmd 编码问题,/C:"通过" 断链实测)——过滤含中文输出改用 node -e/PowerShell 或反向 ASCII 模式(如 /V /C:"WARN"),含中文 findstr 的链式命令分步执行。Confidence: 0.9
- Playwright:playwright skill 的 wrapper 是 bash 脚本在本机跑不了——用 powershell 工具直调 CLI:`npx --yes --package @playwright/cli playwright-cli open|resize|screenshot|press|run-code|reload|close`,截图落在仓库根 .playwright-cli/(未跟踪);play 页有 localStorage 游标:reload 后恢复上次位置、ArrowRight 可能落/夹在半集或末步——先按键再截图确认落点(占位章页显示章名+拍号为标记),ArrowLeft 校正,ArrowRight 次数从封面预算(1 封面拍 + 累计各章拍数);视觉验收失败的补救路径例外(常规交付仍归用户):起 dev server、1920×1080 逐步截图、定位具体渲染缺陷(裁切/缺留白/死区/文字碰撞)修复重截至通过,收尾关浏览器并杀掉 agent 所属 dev server/端口再邀验收。Confidence: 0.75
- 后台 dev server 空日志≠必然静默退出(Vite 顺延下一空闲端口时日志也可能暂空,实例 ep05:日志空但实际已在 5174 存活):先查 shell task 状态+任务日志,随即循环探测 5173–5178 等连续端口(Invoke-WebRequest 2s 超时)定位实际端口——有响应直接用实际端口交付预览 URL;无响应才判定静默退出,后台重启 pnpm dev,重启后立即跑截图批。Confidence: 0.6
- Scratchpad 验证脚本(解析中文 markdown):行锚定 regex 前先 CRLF→LF 归一(.replace(/\r\n/g, "\n"));regex 保持 ASCII 锚定(如 `\d+ steps\D+(\d+)s`)——中文标点(—、(、·)经 cmd 传参会损坏并静默失配;regex 静默失败时先 JSON.stringify dump 实际行再改模式;抽取 TS 数组字面量给 JSON.parse:在 `= [` 与末个 `]` 之间切片并去尾逗号——类型注解括号与 TS 尾逗号会挫败朴素首个 `[` 提取;scratchpad 在 Temp 工作区之外——相对 import 相对脚本所在目录解析必错、workspace 相对路径取不到文件,引仓库工具/写仓库文件一律用绝对 workspace 路径 + pathToFileURL 动态导入(cmd 里 %COMMANDCODE_SCRATCHPAD% 可展开脚本路径本身)。Confidence: 0.8
- TTS 合成环境坑:shell 里残留的 `PRESENTATION_TTS_VOICE`(如 cosyvoice 音色)会被 edge provider 透传报错——显式 `--voice` 覆盖或先清空该环境变量;`edge-tts` 裸命令 spawn 失败时 shared.mjs 的 PowerShell 兜底会把 `.exe` 当 `.ps1` 交给 `-File`(共享工具既有 bug,不擅自修)——用 `EDGE_TTS_COMMAND` 指向 edge-tts.exe 完整安装路径绕开并在报告中备案。Confidence: 0.8
- 同一文件并行批量 edit 后视图可能滞后于磁盘:一批并行 edit 同一文件后,后续工具视图可能仍显示旧内容(实测:4 条收紧 edit 全部落盘但中间视图未刷新)——判定编辑成败一律以重读磁盘逐处核对为准,不凭旧快照断言竞态丢失,也不凭旧快照重复重放编辑。Confidence: 0.6
- episode 章图片素材导入:tsconfig `types` 含 `vite/client`(png 等资源模块已全局声明,无需自写 .d.ts);沿用 sibling 先例以相对路径导入章 assets 占位图(小写命名,如 `import m001 from "./assets/m001.png"`)。Confidence: 0.7
- Subagent 消耗可见性与生命周期:subagent 完成收尾时框架在结果里附加 `<usage>` 块(total_tokens / tool_uses / turns / duration_ms),逐 agent 实测数据可直接引用作复盘的成本治理依据(用户会主动询问 subagent token 消耗);主线程自身消耗、运行中 agent 的实时消耗均读不到——须等完成返回;后台 agent 随会话关闭而终止,会话收尾前未完成的 agent 要么留会话等完、要么按"从已提交工件重派"路径干净重启(已验证重派成本低)。Confidence: 0.7
